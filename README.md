# かんたん動画分割

iPhoneで撮った動画を、約1分50秒（前後5秒ほど）ごとに自動で分割して保存できるWebアプリです。
Safariで開いて「ホーム画面に追加」すると、アプリのように使えます。

## 特長

- 動画をどこにもアップロードしない（処理はすべて端末内のブラウザで完結）
- 各パーツがだいたい1分50秒（前後5秒ほど）になるように分割
- 保存前に、元動画の「何分何秒〜何分何秒」だったかを確認できる
- 再エンコードをしない方式なので、画質を落とさずに分割できる（動画の大きさ・パーツ数により数秒〜数分）
- 各パーツの撮影日時は、分割した日ではなく元動画の撮影日時を引き継ぐ。写真アプリ内では、元動画の直後にパーツ1・2・3…の順で並ぶ

## ファイル構成

```
0_PWAアプリ/
├── index.html      アプリ本体の画面
├── style.css        見た目
├── app.js            動画分割のロジック
├── manifest.json     ホーム画面追加用の設定
├── sw.js             オフライン表示用の簡易キャッシュ
├── manual.html       使い方ガイド（アプリ内の「使い方」から開く）
├── icons/            アプリアイコン（180/192/512px）
└── README.md         このファイル
```

## 公開してiPhoneから使う方法（GitHub Pagesの手順）

このアプリはファイルを開くだけ（`file://`）では、写真の選択やホーム画面追加がうまく動かないことがあります。
無料で簡単な方法として、GitHub Pagesでの公開をおすすめします。パソコンの操作だけで完結し、コマンド入力は不要です。

### 手順1：GitHubのアカウントを用意する

すでにお持ちの場合はこの手順は飛ばしてください。お持ちでない場合は、[github.com](https://github.com/) の右上「Sign up」からアカウントを作成してください（無料）。

### 手順2：新しいリポジトリ（保存場所）を作る

1. GitHubにログインした状態で、右上の「＋」ボタン→「New repository」をクリックします。
2. 「Repository name」に、好きな名前を入力します（例：`video-splitter`。半角英数字が無難です）。
3. 「Public」が選ばれていることを確認します（**Private（非公開）にすると、無料プランではPagesが使えません**。動画そのものはこのアプリの外に出ないので、コードだけが公開されても実害はほとんどありません）。
4. 「Add a README file」などのチェックは入れないままで構いません。
5. 「Create repository」をクリックします。

### 手順3：ファイル一式をアップロードする

1. 作成されたリポジトリの画面で、「Add file」→「Upload files」をクリックします。
2. パソコンでこのフォルダ（`0_PWAアプリ`）を開き、中に入っている**ファイルとフォルダをすべて選択**します（`index.html`、`style.css`、`app.js`、`manifest.json`、`sw.js`、`manual.html`、`README.md`、`icons` フォルダ）。
   - ※ `0_PWAアプリ` フォルダ自体ではなく、**その中身**を選ぶのがポイントです。
3. 選択した状態のまま、ブラウザの「Drag files here」の枠の中にドラッグ＆ドロップします（`icons` フォルダごとドロップすれば、中の画像も一緒にアップロードされます）。
4. 一覧に `index.html` などが表示されたことを確認し、下にスクロールして「Commit changes」（緑色のボタン）をクリックします。

### 手順4：GitHub Pagesを有効にする

1. リポジトリ画面の上部にある「Settings」タブをクリックします。
2. 左側のメニューから「Pages」をクリックします。
3. 「Build and deployment」の「Source」が「Deploy from a branch」になっていることを確認します。
4. 「Branch」のところで、`main`（または `master`）と `/ (root)` を選び、「Save」をクリックします。
5. 数分待つと、ページ上部に「Your site is live at `https://(ユーザー名).github.io/(リポジトリ名)/`」のように、公開されたURLが表示されます。

### 手順5：iPhoneで開いて、ホーム画面に追加する

1. iPhoneのSafariで、手順4で表示されたURL（`https://(ユーザー名).github.io/(リポジトリ名)/`）を開きます。
2. 画面下の「共有」ボタン（四角から矢印が上に伸びたアイコン）をタップします。
3. メニューを下にスクロールし、「ホーム画面に追加」をタップします。
4. 右上の「追加」をタップします。
5. ホーム画面に増えたアイコンをタップすれば、次回からアプリのように開けます。

### アップデートしたいとき

あとでファイルの内容を直したくなったら、同じリポジトリの画面でファイルを開き、鉛筆マーク（Edit）で編集して「Commit changes」するか、手順3と同じ要領で「Upload files」から上書きアップロードすれば、数分後に公開ページにも反映されます。

### 家族・友人限定で共有したい場合

上記の方法は、URLを知っている人なら誰でもアクセスできる状態になります。もっと限定的に共有したい場合は、Netlifyの「Password Protection」機能（有料プラン）など、パスワード付きで公開できる他のホスティングサービスもご検討ください。

### 手元のパソコンで動作確認だけしたい場合

Node.jsが入っていれば、このフォルダで以下のコマンドを実行すると、パソコンのブラウザで確認できます（iPhoneの「ホーム画面に追加」を試すにはインターネット上への公開が必要です）。

```bash
npx serve .
```

## 技術メモ

- 動画の分割処理には [ffmpeg.wasm](https://ffmpegwasm.netlify.app/) を使用しています（CDN経由で読み込み、インターネット接続が必要なのは初回のみです）
- 分割は「再エンコードなし（ストリームコピー）」方式です。動画を圧縮し直さずに、元のデータのまま区切って保存するため、画質の劣化がなく、処理も高速です。その代わり、区切り位置は指定した秒数ちょうどではなく、直後のキーフレーム（1〜2秒程度のズレ）になります
- 動画1本ずつ・パーツ1個ずつ順番に処理します（動画全体をまとめて処理すると、元動画とほぼ同じ量のデータを同時にメモリ上へ抱えることになり、大きい動画でメモリ不足になりやすいため）。パーツごとに独立してキーフレーム位置から切り出すため、**パーツの境目で1〜2秒ほど内容が重複する**ことがあります（順番が入れ替わることはありません）
- 保存はWeb Share API（共有シート）経由です。「ビデオを保存」「"ファイル"に保存」などを明示的に選んでもらう方式のため、保存先が分からなくなりにくく、保存の成否も画面に反映されます。この機能が使えないブラウザ（PCのブラウザなど）では、従来のダウンロード方式に自動で切り替わります
- 対応ブラウザは最新のSafari（iPhone）を想定しています。PC版Chromeでも動作します
- 動画が非常に長い・高画質な場合、動画データを丸ごと端末のメモリ上に読み込む都合上、メモリ不足で処理に失敗する（またはタブごと再読み込みされてしまう）ことがあります。前者の場合はアプリ内に「端末のメモリが不足していないか確認してください」というエラーメッセージが表示されます
- 実機での検証で、337MBの動画は成功、724MBの動画は読み込み開始後すぐにタブがクラッシュすることを確認しています。`SIZE_WARN_BYTES`（app.js、既定450MB）を超えるファイルを選ぶと、処理を始める前に警告を表示します（強制的にはブロックしません）
